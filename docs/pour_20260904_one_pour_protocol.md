## Workarounds using the existing recordings

`experiments/pour/pour_conservation_audit.py` implements two diagnostic estimates,
without modifying the original observations or using the reported endpoint in
normalization. For volume proxies S (source) and R (receiver), and initial source
proxy S0, they are:

- two-cup ratio: `300 * R / (S + R)`;
- source depletion: `300 * (1 - S / S0)`.

The ratio cancels an unknown common multiplicative gain. It does not cancel
different gains in the two cups or pose-dependent refraction/segmentation errors.
During flow, the source-depletion estimate also includes liquid in flight. A
reliable fraction is sufficient to recover volume from 300 mL, but an image-area
ratio is not automatically a volume ratio. The lip-head geometry is still required
for viscosity identification.

In the 60-degree recording, the current deep-source ratio changes from about
154 mL near 8.2 s to 136 mL after return. That nonphysical decrease rules out
promoting simple normalization to the production readout. The loose-source
initial-fill normalization gives a settled endpoint of about 152 mL, closer to
159 mL, but its time curve still varies with pose.

A matched-pose diagnostic using five pre-pour and five post-return frames per run
predicts about 39.2, 73.8 and 151.7 mL from source depletion for 45, 50 and 60 degrees.
Only the initial 300 mL enters that normalization. This uses the 60-degree source
grasp candidate for all episodes, which remains an assumption; it is not evidence
of a validated per-episode pose. Errors remain approximately 9, 5 and 7 mL.

Additional diagnostics under `out/pour_wf/readout_workaround/` found:

- Fitting the local opaque table plane gives camera-dependent height estimates
  differing by approximately 12 mm at the receiver's RGB-derived location.
  The side plane's normal is about 1.64 degrees from the nominal vertical.
- Fitting a free receiver orientation to its empty contours improves coordinate
  RMS from 1.33 to 0.57 pixels, but the tested final frame changes only from about
  129 to 134 mL, still below 159 mL.
- A continuous colour-versus-ray-length model calibrated only on the 60-degree
  endpoint does not transfer adequately to the other recordings and was rejected.

These are diagnostics, not accepted changes to physical cup dimensions, camera
calibration, or the production observation curve.

An endpoint-only inversion of the existing hydrostatic brink model was also
tested. It integrates the source volume as a latent state and solves viscosity
from initial 300 mL and final 159 mL for the 60-degree recorded motion. This uses
one pouring experiment, but changes the original closed-form time-weak method;
it must not be presented as the same identification algorithm. The full MPM
forward check and geometry uncertainty must be assessed separately. Other angles'
endpoints are comparison data, not fitting targets in that prototype.

## Independent static optical calibration remains an option

An alternative to the existing-recording workarounds is an independent calibration of the measuring
instrument, rather than using the three experimental endpoints as calibration
points. It involves no additional robot pour. Report this instrument calibration
separately in the paper; the claim is one dynamic pour for viscosity identification
after camera and cup calibration.

1. Use the same receiver cup, dyed liquid and existing recording cameras. Keep
   the cameras fixed. Place the receiver as in the 60-degree recording if possible;
   include an empty-cup view so any placement difference can be registered.
2. Record the receiver at approximately 0, 50, 100, 150 and 200 mL. Record the actual
   independently measured amount at each level, rather than treating the nominal
   fill as exact. Include the measurement method and any known uncertainty.
3. Keep the receiver fixed between fills and record a few seconds after settling
   at each level, using both existing cameras at their normal recording resolution.
   Save the original camera recordings and metadata, rather than phone photographs
   or screenshots. Keep the usual lighting and avoid automatic-exposure changes
   within a calibration clip where the acquisition software allows this.
4. Record which timestamps or clips correspond to each fill. The template
   `out/pour_wf/volume_readout_audit/static_fill_template.csv` has blank measurement
   and frame fields; its nominal fill levels are requests, not observations.

Fit the camera readout using those independent instrument measurements and the
60-degree identification recording only. Check intermediate levels and occlusion
sensitivity before refitting viscosity. Matching the 159 mL endpoint alone is not
enough to establish the shape of the time curve. Freeze the resulting method
before running the 45- and 50-degree validation predictions. If the corrected
identification curve still conflicts with the brink model, investigate that
within the identification data rather than retuning against validation results.
